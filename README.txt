# GameHub Design — Website Game & Jasa Desain

## Struktur file
- index.html  → struktur halaman
- style.css   → seluruh tampilan/UI
- script.js   → data produk, filter, pencarian, keranjang, modal, dan interaksi

## Cara menjalankan
1. Simpan ketiga file dalam satu folder.
2. Buka `index.html` menggunakan browser.
3. Tidak membutuhkan server untuk demo UI ini.

## Fitur yang sudah tersedia
- Desain homepage terinspirasi dari screenshot referensi dengan identitas visual yang dibuat sendiri.
- Dua layanan utama: Game dan Jasa Desain.
- Klik "Game" untuk menampilkan:
  - Diamond/top up
  - Skin/item
  - Voucher/gift card
- Klik "Jasa Desain" untuk menampilkan:
  - Spanduk
  - ID Card
  - Flyer
  - Logo
  - Branding UMKM
  - Feed Instagram
  - Thumbnail
  - Brosur
  - Poster
  - Kemasan
- Harga produk.
- Search/pencarian.
- Filter kategori.
- Detail produk.
- Keranjang belanja.
- Modal login demo.
- Responsive untuk desktop, tablet, dan mobile.

## Catatan
Ini adalah frontend/demo. Login, database, pembayaran, upload brief desain, status pesanan, dan WhatsApp order belum terhubung ke backend.
